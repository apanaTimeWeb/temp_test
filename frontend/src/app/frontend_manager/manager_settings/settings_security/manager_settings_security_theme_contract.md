# Settings Security — Theme Contract

- All colors must use semantic tokens (`primary`, `background`, `card`, `border`, `muted`, `foreground`).
- Success states must use semantic emerald tokens (`emerald-500`, `bg-emerald-500/10`).
- Warning / Action states must use semantic amber tokens (`amber-500`, `bg-amber-500/10`).
- Danger / Revoke states must use semantic rose tokens (`rose-600`, `bg-rose-500/10`).
- Information banners must use semantic blue tokens (`blue-500`, `bg-blue-50/50`).
- QR code rendering must render crisp paths with high contrast (`fill="#0f172a"`).
- Dark mode compatibility is mandatory across all cards, modals, and tables.
