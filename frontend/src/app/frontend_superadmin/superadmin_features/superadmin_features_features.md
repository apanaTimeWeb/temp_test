# Superadmin Features Domain - Feature Specifications

## Domain Responsibility
Centralized multi-level feature governance, plan entitlement mapping, and emergency platform killswitches across all 16 library modules.

## Sub-Modules
1. **Features Overview (`features_overview`)**:
   - 16-module registry card grid and matrix table views.
   - 3-level feature resolution: Level 1 (Platform Default), Level 2 (Plan Entitlements), Level 3 (Tenant/Branch Custom Overrides).
   - Real-time API Guard simulation terminal with cURL generation and HTTP 200/403 status tracing.
   - Bulk activation, deactivation, and tenant-specific exception management.
