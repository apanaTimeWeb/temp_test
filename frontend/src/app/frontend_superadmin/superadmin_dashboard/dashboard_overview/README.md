# SuperAdmin Dashboard Overview

## Overview
Provides a real-time, comprehensive overview of the entire SaaS multi-tenant platform: KPI cards, health indicators, revenue telemetry, operational activity, and security alerts.

## Features
- **12 Top KPI Cards:** Total Libraries, Active Accounts, Suspended, Total Branches, Active Branches, Admins, Staff, Total Members, Monthly Revenue, Pending Payments, Expiring Subscriptions, Storage Usage.
- **14 Additional Operational Sections:** Recent Accounts, Recent Branches, Latest Logins, Failed Logins, Pending Branch Requests, Upgrade Requests, Payment Alerts, Expiry Alerts, Server Health, DB Health, Background Jobs, SuperAdmin Activities, Open Support Tickets, Data Backup Status.
- **Click-Through Deep Navigation:** Clicking on any KPI card or section navigates directly to its detailed listing.
