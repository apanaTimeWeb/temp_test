# SaaS Pricing Plans Catalog

## Overview
This submodule governs SaaS subscription tier configurations, pricing tiers, resource quotas, and platform feature entitlements for SuperAdmin.

## Features
- **Configurable Tiers:** Starter (1 branch), Professional (3 branches), Enterprise Cloud (10+ branches).
- **Quota Controls:** Max Branches, Admins, Staff, Members, Cloud Storage, SMS & WhatsApp credits.
- **Entitlements:** API Access, Data Export, Advanced Reports, Backup Policies, 24/7 Support.
