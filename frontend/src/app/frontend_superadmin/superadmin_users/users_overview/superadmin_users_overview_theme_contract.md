# Superadmin Users Overview Theme Contract

## Visual Invariants
- Error & Not-Found states inherit the unified `frontend_superadmin` dark glassmorphic palette.
- Surface background: `bg-slate-900/40` with `backdrop-blur`.
- Borders: `border-slate-800`.
- Text primary: `text-slate-200`, secondary: `text-slate-400`.
- Primary CTA buttons: `bg-indigo-600 hover:bg-indigo-500 text-white`.
