# Users, Roles & Permissions Management

## Overview
Provides granular role-based access control (RBAC), multi-factor authentication (MFA) enforcement, security audit logs, and permission matrix configuration.

## Features
- **10 Core Roles:** SuperAdmin, Support Admin, Finance Admin, Library Admin, Branch Manager, Librarian, Accountant, Receptionist, Communication Staff, Custom Staff Role.
- **10 Individual Module Actions:** View, Create, Edit, Delete/Archive, Approve, Reject, Export, Print, Download, Manage Settings.
- **Security Audit Modal:** MFA toggle, Session force logout, Lockout toggle, Security event trail.
