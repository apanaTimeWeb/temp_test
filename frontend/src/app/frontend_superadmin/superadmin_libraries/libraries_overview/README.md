# Library Management & Multi-Tenant Provisioning

## Overview
Governs library account creation, organization details, main admin invitation & MFA setup, branch provisioning (default max 3 branches), and workspace lifecycle.

## Features
- **Organization Profile:** Legal name, Owner, Contact, Address, Timezone, Branding Logo.
- **Admin Setup:** One-time invitation link, MFA enforcement, secure credentials.
- **Branch Provisioning:** Multiple branches (default 3), manager assignment, working hours.
