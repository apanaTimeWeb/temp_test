# Theme Contract — Superadmin Analytics Usage Reports

## Consumed Design Tokens
- Backgrounds: `bg-background`, `bg-card`, `bg-muted`
- Text: `text-foreground`, `text-muted-foreground`
- Borders: `border-border`
- Status Accents:
  - Emerald (Usage Primary): `text-emerald-400`, `bg-emerald-500/10`, `border-emerald-500/20`
  - Sky (Members/API): `text-sky-400`, `bg-sky-500/10`
  - Purple (Storage): `text-purple-400`, `bg-purple-500/10`
  - Amber (Warning Quota): `text-amber-400`, `bg-amber-500/10`

No arbitrary hex codes or raw RGB values.
