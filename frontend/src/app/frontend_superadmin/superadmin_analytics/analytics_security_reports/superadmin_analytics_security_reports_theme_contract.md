# Superadmin Analytics — Security Reports: Theme & Styling Contract

- **Primary Accent**: Rose / Crimson (`text-rose-400`, `bg-rose-500`, `border-rose-500/20`) representing security vigilance.
- **Backgrounds**: `bg-card/70` with `backdrop-blur-xs` and subtle borders `border-border/70`.
- **Status Badges**:
  - `CRITICAL`: `bg-rose-500/20 text-rose-300 border-rose-500/40`
  - `HIGH`: `bg-orange-500/20 text-orange-300 border-orange-500/40`
  - `MEDIUM`: `bg-amber-500/20 text-amber-300 border-amber-500/40`
  - `LOW`: `bg-slate-500/20 text-slate-300 border-slate-500/40`
- **Typography**: Inter / system font with monospace formatting for IP addresses, library codes, and timestamps.
- **Responsiveness**: Fluid layout spanning mobile stacked views (`grid-cols-1`) to widescreen 6-column KPI cards (`xl:grid-cols-6`).
