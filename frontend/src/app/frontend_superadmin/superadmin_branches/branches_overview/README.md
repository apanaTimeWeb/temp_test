# SuperAdmin Branch Management

## Overview
Governs platform-wide library branch operations, manager assignments, status transitions, quota enforcement, and soft-delete archive/restore controls.

## Features
- **14 Core Branch Actions:** Create, Edit, Activate, Suspend, Deactivate, Close, Transfer Manager, Change Admin, Change Plan, View Details, View Activity, View Reports, Export Data, Restore.
- **Branch Conditions:** Duplicate branch code prevention, tenant isolation, dues check before close, soft deletion only, branch-level audit logs.
