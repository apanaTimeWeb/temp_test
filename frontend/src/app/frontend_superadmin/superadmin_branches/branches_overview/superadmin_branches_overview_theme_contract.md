# Theme Contract & Token Mapping

- **Primary Accent**: Indigo (`#6366f1` / `from-indigo-600 to-indigo-500`)
- **Status Operational**: Emerald (`bg-emerald-500/15 text-emerald-300 border-emerald-500/30`)
- **Status Suspended**: Rose (`bg-rose-500/15 text-rose-300 border-rose-500/30`)
- **Status Closed/Archived**: Slate / Amber (`bg-amber-500/15 text-amber-300 border-amber-500/30`)
- **Action Buttons**: Single-line horizontal container with individual action buttons, minimum 32px hit target, rounded-lg.
- **Card Backgrounds**: Solid dark `#0f172a` and `#0a0d22` with indigo border highlights.
