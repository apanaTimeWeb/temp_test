# Superadmin Usage Overview - Theme Contract

- **Domain Theme**: Sky / Slate Luxury Tech
- **Primary Accent**: `sky-400` / `sky-500` / `blue-600`
- **Surface**: `bg-slate-900/60`, `bg-slate-950/80`, `border-slate-800`
- **Overage Badges**:
  - Normal (<80%): `bg-emerald-500/20 text-emerald-400 border-emerald-500/40`
  - Warning (80-89%): `bg-yellow-500/20 text-yellow-400 border-yellow-500/40`
  - Critical (90-99%): `bg-amber-500/20 text-amber-400 border-amber-500/40`
  - Exceeded (100%): `bg-red-500/20 text-red-400 border-red-500/40`
- **Typography**: Inter / Sans font stack with tabular numeric figures for quotas and percentages.
