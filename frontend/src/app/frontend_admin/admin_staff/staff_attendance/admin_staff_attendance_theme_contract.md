# Staff Attendance — Theme Contract

- Surface container: `bg-card`, `border-border`, `rounded-xl`, `shadow-sm`
- Primary action: `bg-primary`, `text-on-primary`, `hover:bg-primary-hover`
- Secondary action: `border-border`, `text-text-primary`, `hover:bg-surface-hover`
- Status tokens:
  - Present: `bg-success-bg`, `text-success-text`, `border-success-border`
  - Late: `bg-warning-bg`, `text-warning-text`, `border-warning-border`
  - Absent / Missed: `bg-danger-bg`, `text-danger-text`, `border-danger-border`
  - On Leave: `bg-surface-highlight`, `text-text-secondary`, `border-border`
