# Theme Contract — Admin Accounts Daily Settlement

## Consumed Design Tokens

| UI Surface / Element | Token Class | Purpose |
| :--- | :--- | :--- |
| Page Canvas | `bg-canvas` | Top-level background |
| Cards & Table Container | `bg-card`, `border-border` | Layer 1 surface elevation |
| Table Header Row | `bg-muted/60`, `text-muted-foreground` | Header differentiation |
| Table Row Hover | `hover:bg-muted/30` | Subtle interactive hover |
| Focus Rings | `focus-visible:ring-2 focus-visible:ring-primary` | Accessible focus state |
| Pending Status Badge | `bg-warning-bg`, `text-warning-text`, `border-warning/30` | Pending admin clearance |
| Approved Status Badge | `bg-success-bg`, `text-success-text`, `border-success/30` | Approved & verified handover |
| Discrepancy Badge | `bg-destructive/15`, `text-destructive`, `border-destructive/30` | Shortage or audit alert |
| Primary Action Buttons | `bg-primary`, `text-on-primary`, `hover:bg-primary/90` | Main interactive actions |
| Success Action Buttons | `bg-success`, `text-white`, `hover:bg-success/90` | Approve & clear handover |
| Destructive Action Buttons | `bg-destructive`, `text-white`, `hover:bg-destructive/90` | Flag discrepancy |
| Skeleton Loaders | `bg-surface-highlight`, `motion-safe:animate-pulse` | Loading layout skeleton |
