# Password Recovery — Theme and Accessibility Contract

- Reuse host semantic tokens: `bg-page`, `bg-card`, `bg-input`, `text-primary`, `text-secondary`, `text-danger`, `bg-danger-bg`, `bg-success-bg`, and `text-on-primary`.
- Preserve visible labels, required-field indicator, help text, and validation association.
- Keep focus-visible rings and keyboard-operable links/buttons.
- Keep pending controls disabled and show reduced-motion-aware progress feedback.
- Accepted feedback uses a live status region and generic-safe recovery wording.
- Maintain English/Hindi translation parity for the recovery copy represented in this module.
- Do not introduce hard-coded brand colors or claim delivery of a recovery message.
